# vial-ts

This repository now contains a TypeScript + Svelte baseline for a future web-based version of the Vial UI.

## Development

```bash
npm install
npm run dev
```

## Validation

```bash
npm run check
npm run build
```

## Current scope

- Bootstraps a Svelte app with TypeScript support.
- Replaces the template landing page with a `vial-ts` UI shell.
- Includes an initial keymap/layer preview component to guide future parity work with the Python Vial UI.
